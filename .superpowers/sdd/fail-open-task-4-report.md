## Устранённая причина

Codex 0.146.1 проверяет ответы жизненных хуков по закрытым схемам. Общий
аварийный ответ надстройки содержал дополнительные верхнеуровневые поля
`code` и `reason`, которые не разрешены схемой Stop-хука. Поэтому корректное
по смыслу продолжение превращалось в ошибку разбора JSON уже внутри Codex.

Единый аварийный ответ теперь содержит только поля, допустимые для всех
используемых событий:

```json
{
  "continue": true,
  "systemMessage": "SMART_HOOK_DEFERRED: <причина>"
}
```

Блокирующий ответ Stop-хука с `decision=block` и `reason` не менялся: эти поля
разрешены его схемой и используются только для доказанно незавершённого
умного маршрута.
