# codex-settings

Центральный каталог настроек, эксплуатационных руководств и архитектурных
решений Codex. Подробные команды и диаграммы находятся в профильных
документах.

## Быстрые маршруты

| Задача | Состояние | Куда перейти |
|---|---|---|
| Понять, как выбираются модель и уровень рассуждения для отдельной подзадачи | Реализовано для Codex 0.144.4, умный режим выключен по умолчанию | [Как проходит умный ход](plugins/codex-smart-subagents/README.md#как-проходит-умный-ход) |
| Установить, проверить, включить на пробу или откатить адаптивных субагентов | Операторская процедура; готовность установки не равна готовности маршрута | [Операционная инструкция](docs/runbooks/adaptive-subagents-v2-operations.md) |
| Использовать прежние профили, интерактивные волны, защиту файловых дескрипторов или локальную очередь | Совместимый автономный процесс; фактическое внешнее состояние проверяется перед запуском | [Автономная работа Codex](docs/guides/autonomous-workflow.md) |
| Настроить полный доступ корневой сессии | Операторский рецепт, а не подтверждение текущего пользовательского файла | [Полный доступ Codex](docs/guides/full-access.md) |
| Перейти со старого автономного процесса на адаптивный режим | Старый процесс сохраняется до явного включения нового | [Руководство по переходу](docs/migrations/adaptive-subagents-v2.md) |
| Разобрать архитектуру внешнего контроллера | Решение принято | [Архитектурное решение](docs/decisions/001-adaptive-subagents-external-controller.md) |
| Проверить границы доверия и запрещённые обещания | Действующая модель угроз | [Модель угроз](docs/threat-models/adaptive-subagents.md) |

## Совместимость

На момент подготовки этого каталога локальный исполняемый файл сообщает
`codex-cli 0.144.5`. Адаптивные субагенты версии 0.1.0 проверены только с
Codex 0.144.4, поэтому их нельзя включать на 0.144.5 без отдельной проверки
совместимости. Автономные профили и пользовательский `config.toml` находятся
вне репозитория и проверяются заново перед использованием. Реальный адаптивный
маршрут дополнительно требует `darwin-arm64`, частный файловый `auth.json` и
чистый канонический репозиторий без связанных рабочих копий, символических
ссылок, подмодулей и Git LFS; точные пределы приведены в операционной
инструкции.
