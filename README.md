# codex-settings

Центральный каталог настроек, эксплуатационных руководств и архитектурных
решений Codex. Краткий статус и точные переходы находятся здесь, а договоры,
команды и диаграммы — в профильных документах.

## Совместимость

Версия локального Codex в этом каталоге не фиксируется и перед работой
проверяется заново. Реализация `codex-smart-subagents 0.1.0` выключена по
умолчанию и жёстко проверена только на историческом снимке Codex `0.144.4`.
Договоры варианта 2 и планируемого выпуска `0.2.0` являются проверяемым
проектом реализации: исполняемый маршрут, чистая установка, испытания
аварийных окон и пробное включение ещё не готовы.
