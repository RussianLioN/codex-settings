# codex-settings

Центральный каталог настроек, эксплуатационных инструкций и архитектурных
решений Codex. В этой ветке собран путь адаптивных субагентов
версии `0.2.0`. Живая проверка опубликована в
[итоговом отчёте](docs/analysis/2026-07-20-adaptive-subagents-v2-validation.md).

## Совместимость

Установщик каждый раз проверяет стабильную версию Codex. Для выпуска
расширения 0.2.0 исходный код точек подключения проверен у версий `0.144.4`,
`0.144.5`, `0.144.6` и `0.145.0`; только они допускаются к адаптивному пути. Затем
сверяются фактические возможности исполняемого файла и доступные учётной
записи пары «модель — уровень рассуждения». Неизвестная версия или
недостаточная возможность закрывает адаптивный путь без скрытой замены
модели. Команда `codex` остаётся обычным Codex. Установленная команда
`codex-smart`
включает адаптивный интерактивный путь только для поддержанного вида запуска;
служебные подкоманды и неподдержанные параметры передаются обычному Codex.
Явно заданная модель корневой сессии сохраняется, но не подменяет выбор моделей
для субагентов. Повторный запуск установщика с тем же отпечатком входов
возвращает `unchanged`; изменение исходников, лексического пути или содержимого
выбранного Codex, а также канонического пути или содержимого выбранного
Python проходит журналируемое обновление. Для рабочего контура требуется
Python не ниже `3.11`; внешние Python-пакеты ему не требуются. `jsonschema` и
`referencing` остаются средствами проверки для разработки и не копируются в
активацию.
Откат возвращает только целую предыдущую активацию. Удаление поддерживается
только с `--retain-data`: база, резервные копии, карантин и отдельная точка
восстановления сохраняются.
