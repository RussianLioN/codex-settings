# Модель угроз адаптивных субагентов

## Защищаемые объекты

- исходное рабочее дерево, индекс, служебные данные и ссылки Git;
- пользовательские учётные данные Codex;
- содержимое файлов вне разрешённого снимка;
- целостность выбранной модели, уровня рассуждения и профиля прав;
- очередь, база состояния, журналы и карантинные кандидаты;
- ресурсы компьютера и лимиты учётной записи.

## Границы доверия

1. Пользовательский запрос и вывод любой модели считаются недоверенными.
2. Корневая сессия с полным доступом считается доверенным координатором, но не
   изолирующей средой.
3. Контроллер, каталог, схемы и утверждённые команды проверки доверены.
4. Дочерний `codex exec`, его события JSONL и телеметрия недоверены до проверки.
5. Исходный репозиторий доступен дочернему процессу только через снимок.
6. Карантин Git физически отделён от исходного каталога `.git`.

## Основные злоупотребления и меры

| Угроза | Мера |
|---|---|
| Подмена маршрута или модели | Модель не передаёт эти поля; контроллер вычисляет их по каталогу и сохраняет хеш решения |
| Повторный запуск одного запроса | Идемпотентный ключ, срок действия маршрута и транзакция SQLite |
| Выход за разрешённый путь | Нормализация путей, запрет символьных ссылок и проверка принадлежности снимку |
| Чтение секретов | Профиль с минимальными путями, запрет типовых файлов секретов и отрицательные пробы |
| Сетевая утечка | Сеть выключена в профилях дочерних процессов |
| Вложенное разрастание агентов | `agents.max_threads = 1`, `agents.max_depth = 1`, отключён `multi_agent` |
| Командная инъекция | Команды проверки выбираются только из доверенного каталога и запускаются массивом аргументов без оболочки |
| Изменение исходного Git | Снимок без записи, отдельный пустой каталог запуска и отдельное карантинное хранилище |
| Подмена результата телеметрией | Сверка JSONL, идентификатора диалога и локальной аттестации; телеметрия не доказывает профиль прав |
| Истощение ресурсов | Глобальные и корневые пределы, ограничение очереди, размера входов, времени, памяти, файловых дескрипторов и диска |
| Повреждение состояния после сбоя | Журнал намерений до внешнего действия, транзакции, аренды, пульс и восстановление |
| Утечка через журналы | Белый список полей, хеши вместо запросов и путей, отсутствие текста запросов в телеметрии |

## Запрещённые обещания первой версии

- автоматическое применение, слияние или публикация изменений;
- доказательство профиля прав только по телеметрии;
- полная безопасность корневой сессии с полным доступом;
- поддержка произвольной версии Codex CLI;
- поддержка подмодулей, больших файлов Git, символьных ссылок или внешних
  рабочих деревьев в области записи;
- гарантированная доступность конкретной модели без предварительной проверки
  каталога.
