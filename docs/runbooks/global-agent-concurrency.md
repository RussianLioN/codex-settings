# Глобальная политика субагентов

Связанная задача: https://github.com/RussianLioN/codex-settings/issues/11.

Канонический блок находится в `config/global-agent-concurrency.md`.
Установщик заменяет `{{ADMISSION_BACKEND}}` на явно зарегистрированный `fd-doctor`
для macOS Air/Pro или `native` для Linux/Windows. Старый блок ограничителей
заменяется новым без изменения постороннего текста. Повторное применение безопасно.
Общий предел — 19 субагентов одной сессии, корень отдельно. Минимальный состав
обычной команды выбирается по задаче; полный Consilium сохраняет 19 ролей.

Пакет `config/global-agent-concurrency-payload.json` перечисляет исходники,
целевые корни, относительные пути, способы допуска и SHA-256. Поле `template`
обозначает объединяемый блок AGENTS.md, а не замену всего файла.
`codex_home` — выбранный каталог Codex; `local_bin` и `local_libexec` задаются
установщиком явно. Все файлы пакета проверяются до применения.
Для native не устанавливается оболочечная проверка macOS. Валидатор манифеста
остаётся общей проверкой доверия. Ошибка обязательного doctor не разрешает
переход на native. Временное отключение hooks не отменяет ресурсную проверку.

Доверенный обычный запуск 7–19 использует собственный идентификатор
`parallel-review-wave`, исполнение `flat-trusted-wide-wave`, резерв `chunks<=6`
и точный SHA установленного навыка. Резервная граница 6 и порог доверия сохранены.
Доктор оценивает только запрошенную волну; процессы соседних вкладок не расходуют
её квоту. Завершение роли не доказывает закрытия потока.

Каталог без Git допускает `base_commit: null` только при реальном отсутствии
Git в каталоге и родителях, только чтении и пустых областях записи.

## Интеграция Consilium

Реестр содержит подтверждённые исполнителем SHA Consilium 0.2.3 и сохраняет
совместимые SHA версий 0.2.2 и 0.2.0. Перед установкой сверяйте фактические файлы
пакета с реестром. После любого изменения перечисленных файлов пересчитайте
пакет и проверьте соответствие всех сумм.

Полный `apply_runtime_fd_guardrails.py --apply` также управляет hooks;
для доставки только этой политики используйте ограниченный установщик среды
агентов. Данное изменение не запускает установку и не меняет текущую среду.
