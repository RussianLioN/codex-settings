# Исправление общего срока Stop-хука

## Цель

Исключить внешнее прерывание `Stop hook timed out after 2s`, сохранив отказоустойчивое поведение умного маршрутизатора и возможность безопасно продолжить работу на следующем ходе.

## Контракт

- `UserPromptSubmit`, `Stop` и `SessionEnd` получают внешний срок 5 секунд; `SessionStart` сохраняет 10 секунд.
- Stop использует единый абсолютный внутренний срок 1,5 секунды, отсчитанный от максимально ранней точки процесса до `runpy`, импортов и чтения входа.
- Служебный ранний срок создаёт сам запускатель; значение из окружения не считается доверенным.
- Основная проверка, сохранение результата и подтверждение возобновления используют один и тот же абсолютный срок.
- По исчерпании срока или восстанавливаемой ошибке процесс завершается с кодом 0 и выдаёт корректный JSON с `continue: true` и кодом `SMART_HOOK_DEFERRED`.
- Stop не запускает `smart_plan`; незавершённая работа остаётся в устойчивом состоянии для следующего пользовательского хода.
- Целевое время Stop: 95-й процентиль не выше 1 секунды, 99-й — не выше 1,5 секунды.

## Порядок реализации

1. Зафиксировать красными тестами внешний срок трёх событий, ранний момент создания абсолютного срока, защиту от подстановки окружения, ответ при исчерпанном бюджете и ограничение подтверждения возобновления.
2. Добавить лёгкий ранний запускатель только на стандартной библиотеке Python и передать абсолютный срок обработчику Stop.
3. Перевести все ветви Stop, включая подтверждение возобновления, на общий остаток времени.
4. Добавить единый отказоустойчивый JSON-ответ `SMART_HOOK_DEFERRED` без потери сохранённого состояния.
5. Зафиксировать внешний срок 5 секунд для трёх событий и сохранить 10 секунд для `SessionStart`.
6. Выполнить целевые модульные проверки, полный набор проекта, проверку упаковки и чёрноящичный запуск установленного кандидата.
7. Установить только после успешной рецензии, сохранить контрольные суммы и проверить живой Stop с искусственно исчерпанным бюджетом.
8. При откате восстановить предыдущую активацию через штатный установщик; не редактировать установленное неизменяемое дерево вручную.

## Критерии приёмки

- Нет внешнего timeout при медленном Stop; stdout содержит один корректный JSON, код процесса 0.
- Значение дедлайна создаётся до загрузки модуля и не принимается из пользовательского окружения.
- Подтверждение возобновления не выходит за общий внутренний срок.
- Состояние после `SMART_HOOK_DEFERRED` пригодно для повторной обработки.
- Все целевые и полные проверки проходят из чистого состояния.
