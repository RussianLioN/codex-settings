# Восстановление допуска Consilium 19

Этот репозиторий содержит исходники предварительной проверки широкой волны
Consilium и её изолированный установщик. Он не включает хуки, смарт-запуск или
изменение основного пользовательского профиля.

## Договор допуска

Проверка принимает только закреплённые SHA-256 выпуска Consilium 0.2.0. Врач
возвращает `status`, `wave_size`, `allowed_wave_size`, `capacity_decision` и
`reasons`. Плоская волна из 19 ролей разрешена исключительно при
`status=OK`, `allowed_wave_size=19` и `capacity_decision=ALLOW`.

`WARN` не является разрешением плоского запуска: он сообщает фактический размер
для документированного разбиения. Если локальное предупреждение возникло при
полной широкой вместимости, размер дополнительно ограничивается шестью ролями,
чтобы `allowed_wave_size=19` означал только безусловный допуск. `BLOCK` всегда возвращает
`allowed_wave_size=0`.

## Изолированная установка

Применяйте установщик только с отдельными путями `--codex-home`,
`--installed-doctor` и `--installed-highfd`. Он атомарно устанавливает конфигурацию
предела и полный набор предварительной проверки, создаёт квитанцию v2 и умеет
откатить её без запуска Codex, ChatGPT или хуков. `hooks = false` и существующие
артефакты hooks остаются неизменными.

Проверки и текущий статус приведены в
`docs/analysis/2026-08-13-consilium-19-wide-preflight-rca.md` и
`docs/plans/2026-08-13-consilium-19-wide-preflight-recovery.md`.
